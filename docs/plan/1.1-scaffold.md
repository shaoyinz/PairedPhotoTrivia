# 1.1 Scaffold

**Timebox:** one sitting (~2 h). **Done when** the walking skeleton in §1.1.7 runs end to end on
synthetic data and `uv run pytest` is green — before any real Photos library is involved.

The point of 1.1 is not "create files." It is to freeze three contracts so §1.3–1.9 can be
written in any order, by anyone, without renegotiation:

1. the CSV schema shared by the Swift exporter and the Python reader (§1.1.6),
2. the pure-function signatures that get ported to Swift (§1.1.5),
3. a synthetic end-to-end run, so downstream work is not blocked on Xcode or on the partner's
   export (§1.1.7).

installed package rather than accidentally shadowing it from the working directory.

## 1.1.5 Module contracts — write these signatures now, bodies `raise NotImplementedError`

This is the deliverable. Each is a pure function over plain data, which is what makes the phase-2
Swift port mechanical.

```python
# schema.py — the contract the Swift exporter must match byte for byte
CSV_COLUMNS: tuple[str, ...] = (
    "asset_id", "utc_epoch", "tz_offset_s", "lat", "lon", "is_screenshot",
    "burst_id", "is_burst_pick", "camera_make", "camera_model", "width", "height",
)
CSV_HEADER: str = ",".join(CSV_COLUMNS)

# models.py — all frozen, all slots
PhotoMeta(asset_id, utc_epoch, tz_offset_s, lat, lon, is_screenshot,
          burst_id, is_burst_pick, camera_make, camera_model, width, height)
    .local_epoch -> int      # utc_epoch + tz_offset_s; for local-hour reasoning ONLY, never for matching
    .has_gps     -> bool
BucketKey(geohash6: str, hour_index: int)       # hour_index = utc_epoch // 3600
BucketHash = NewType("BucketHash", bytes)       # HMAC-SHA256 truncated to 16 bytes
LatLon(lat: float, lon: float)
Anchors(person, home: LatLon, work: LatLon | None, home_geohash7, work_geohash7,
        window_days: int, home_nights: int, work_days: int,   # support (distinct days) so §1.8 can flag weak inference
        shared_home: bool | None = None)                      # hand override of the < 1 km rule (§1.6)
TripWindow(start_utc, end_utc, matched_bucket_count, photo_count_a, photo_count_b,   # window is [start_utc, end_utc)
           representative_geohash6, away_reason: str)

# project.py — replaces pyproj; 0.4% error at 44 km, measured
KM_PER_DEG_LAT = 110.574
KM_PER_DEG_LON = 111.320
def to_km(p: LatLon, origin: LatLon) -> tuple[float, float]: ...
def distance_km(a: LatLon, b: LatLon) -> float: ...             # on a's plane; for "is it near"

# filters.py — countable: the report must show what each rule dropped
FilterStats(rule: str, dropped: int)
def drop_screenshots(ps: list[PhotoMeta])       -> tuple[list[PhotoMeta], FilterStats]: ...
def drop_missing_timestamp(ps: list[PhotoMeta]) -> tuple[list[PhotoMeta], FilterStats]: ...
def collapse_bursts(ps: list[PhotoMeta])        -> tuple[list[PhotoMeta], FilterStats]: ...
def apply_all(ps: list[PhotoMeta])              -> tuple[list[PhotoMeta], list[FilterStats]]: ...

# buckets.py
def bucket_key(p: PhotoMeta) -> BucketKey | None: ...          # None when no GPS — not an error
def expand(k: BucketKey) -> frozenset[BucketKey]: ...          # 9 cells x 3 hours = 27 normally
def salted(k: BucketKey, salt: bytes) -> BucketHash: ...       # HMAC(salt, f"{geohash6}|{hour_index}")
def salted_set(ks: Iterable[BucketKey], salt: bytes) -> frozenset[BucketHash]: ...

# matching.py — HASH-BLIND BY CONSTRUCTION
def match(expanded_a: frozenset[BucketHash], raw_b: frozenset[BucketHash]) -> frozenset[BucketHash]: ...

# anchors.py
def local_hour(p: PhotoMeta) -> int | None: ...                # None without a time zone
def infer_anchors(ps, *, person: str, now_utc: int, window_days: int = 90) -> Anchors: ...

# commute.py
CommuteBuffer(origin: LatLon, area: BaseGeometry)   # area on origin's km plane; .covers(p: LatLon)
def commute_buffer(home: LatLon, work: LatLon | None, km: float = 5.0) -> CommuteBuffer: ...
def is_shared_home(a: LatLon, b: LatLon, km: float = 1.0) -> bool: ...
def resolve_shared_home(a: Anchors, b: Anchors, km: float = 1.0) -> bool: ...   # anchors-file override, else distance
def is_away(p: LatLon, buf_a, buf_b, *, shared_home: bool) -> bool: ...   # shared -> outside BOTH; different -> outside EITHER

# trips.py
def sessionize(matched: Sequence[BucketKey], *, gap_hours: int = 6) -> list[list[BucketKey]]: ...   # by hour, not BucketKey order
def cell_center(k: BucketKey) -> LatLon: ...                            # the point a bucket stands for in is_away
def join_nights(sessions, city_a, city_b, *, shared_home, ps_a, ps_b, max_silence_hours=72) -> list[list[BucketKey]]: ...
                                                                        # until either partner is back in their home city
def window(trip, *, reach_hours: int = 3) -> tuple[int, int]: ...       # trip hours ± reach, half-open
def assemble(matched, anchors_a, anchors_b, *, ps_a, ps_b, gap_hours=6, reach_hours=3,
             city_km=25.0, max_silence_hours=72, min_photos=5) -> list[TripWindow]: ...
def backfill(w: TripWindow, ps_a, ps_b) -> TripWindow: ...
```

Three contract details worth fixing in code now, because each is a bug waiting to happen later:

- [x] **`expand` must survive the poles.** `pygeohash.get_adjacent` has no `neighbors()`; the 8
      neighbors are composed from `Direction = Literal["right","left","top","bottom"]`
      (not an enum — it is a `typing.Literal`, so pass the bare strings). Verified: a cell at
      the antimeridian wraps correctly and yields 9 cells; a cell at either pole **raises
      `ValueError: No adjacent geohash to the top…`**. `expand` catches it and returns the
      cells that do exist. *Contract fixed in the `expand` docstring and in strict-xfail tests;
      the body landed in §1.4, and those tests now live, unmarked, in `tests/test_buckets.py`.*
- [x] **`expand` one side only** (already in [§1.4](1.4-buckets-and-matching.md)) — encode that in the names,
      `expanded_a` vs `raw_b`, so a later caller cannot quietly expand both.
- [x] **Make the privacy boundary a test, not a comment.** `tests/test_matching_is_blind.py`
      parses `matching.py` with `ast` and asserts it imports nothing coordinate- or
      timestamp-bearing — `BucketHash` only, never `PhotoMeta`, `BucketKey` or `LatLon`. This is
      the one hard constraint in `CLAUDE.md` that is cheap to enforce mechanically.

## 1.1.6 One CSV schema, asserted on both sides

- [x] `schema.py` owns `CSV_COLUMNS`; `ingest.py` validates against it and fails loudly on a
      mismatch rather than silently reading shifted columns
- [x] The Swift exporter ([§1.2a](1.2-export.md)) writes its header from a constant copied from `CSV_HEADER`, and
      `tests/test_schema.py` pins the exact header string — so when phase 2 changes one side, the
      other side's test fails instead of the data quietly going wrong. *Both halves done:
      `test_schema.py` also reads `CSVRow.header` out of the Swift source and checks it against
      the pinned string.*

## 1.1.7 Walking skeleton — the thing that unblocks everything else

[§1.2a](1.2-export.md) is blocked on Xcode, and the partner's export is blocked on logistics (TestFlight vs. an
Xcode build on their Mac, still open). So 1.1 ends by making real data unnecessary for progress:

- [x] `photoquiz synth --out data/` writes `data/a_photos.csv` and `data/b_photos.csv`: a shared
      home, two different workplaces, weekday commute noise inside both buffers, **two planted
      trips** (one where both partners shot photos, one where only partner A did), a 4-photo
      near-trip that must be rejected by the `>= 5` rule, a burst, a screenshot, and a GPS-less
      run. It also writes the matching `data/labels.csv`, so [§1.8](1.8-evaluation.md)'s evaluation path has ground
      truth from day one.
- [x] Wire the typer commands as thin shells over the pure functions, each printing its stage
      counts: `synth`, `ingest`, `filter`, `buckets`, `match`, `anchors`, `trips`, `report`,
      `sweep`
- [x] `make skeleton` (or a `justfile` target) runs
      `synth → ingest → filter → buckets → match → anchors → trips → report` on the synthetic
      pair and must exit 0 with both planted trips in `data/trips.json` and the near-trip absent.
      Until the stubs are filled this fails at the first `NotImplementedError` — that failure
      moving down the pipeline is the progress metric for §1.3–1.8. *Target is `spike/Makefile`;
      as of 2026-10-01 it passes `synth` and `ingest` and stops at `filter` (§1.3).*
