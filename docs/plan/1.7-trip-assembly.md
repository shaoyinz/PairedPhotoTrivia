# 1.7 Trip assembly (`trips.py`)

- [ ] Sessionize matched buckets by time gap: a gap > 6 h starts a new window (tunable). Start
      here rather than with ST-DBSCAN — it is deterministic, trivially portable to Swift, and
      one parameter. Keep DBSCAN on (scaled space × time) as the fallback if sessionization
      splits or merges trips badly; the report compares them on the same labels.
- [ ] Keep a window only if at least one matched bucket is `is_away`
- [ ] Keep a window only if total photos across both devices ≥ 5
- [ ] Backfill: once a window survives, include every photo from both partners inside it,
      including unmatched and GPS-less ones (covers "only one partner shot that day")
- [ ] Output `data/trips.json`: window start/end UTC, matched bucket count, photo counts per
      partner, representative geohash, away/shared-home reason
