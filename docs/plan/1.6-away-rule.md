# 1.6 Away rule (`commute.py`)

- [ ] `commute_buffer(home, work, km=5.0) -> shapely geometry`: buffer around the straight
      home→work segment, computed on the local km plane from `project.py` ([§1.1.0](1.1-scaffold.md) — not pyproj,
      not an azimuthal-equidistant projection; the flat local plane is accurate to 0.4% at 44 km
      and ports to Swift)
- [ ] `is_away(point, buffers, shared_home: bool)`: shared home → outside **both**;
      different homes → outside **either** is enough (so visiting each other counts)
- [ ] Decide `shared_home` by distance between the two homes (< 1 km ⇒ shared), overridable in
      the anchors file
